Implementation plan · 17 October 2026 · MyDay / video-chunker

Split one video into timed chunks

A local Python command takes a video file, cuts it into pieces of a chosen length, and writes those pieces to a folder on disk.

Goal
Build a Python command that writes a video as a sequence of MP4 chunks of a configurable duration, default 15 seconds, into a local folder.
Architecture
A command-line entry point probes the file with ffprobe, plans cut points in pure Python, then asks ffmpeg to write one MP4 per segment. A JSON manifest records the timeline.
Tech stack
Python 3.11, argparse, subprocess, pytest. ffmpeg 5 or newer and ffprobe on the machine. No runtime Python packages.
Spec
This document is the spec and the plan. The service code is not written yet. Tasks below are the build order.

For agentic workers: use superpowers:subagent-driven-development or superpowers:executing-plans, task by task. The checkboxes on this page remember progress in this browser.

Constraints

  • Python 3.11 or newer.
  • ffmpeg 5 or newer, and ffprobe, available on PATH or passed as flags.
  • One input file per invocation. A shell loop is the way to cut many files.
  • Default chunk length is 15 seconds. --duration sets it, in seconds, and must be longer than one frame.
  • Exact mode is the default. It re-encodes to H.264 and AAC so each cut lands on a frame.
  • Fast mode copies packets and may cut on a later keyframe, so a piece can run past the requested length.
  • Output files are MP4. Names are {stem}_0000.mp4 upward, four digits, starting at zero.
  • The manifest is {stem}.chunks.json in the output folder.
  • A run refuses to replace existing chunk files unless --overwrite is set.
  • More than 10,000 chunks is refused.
  • The tool makes no network calls and adds no runtime pip dependencies.

Approach

Three ways can cut a file into timed pieces. This plan uses the first.

ApproachWhat it costsWhat you get
CLI plus ffmpeg ffmpeg must be installed. One command, a library function beside it, and frame-accurate cuts. Recommended.
HTTP service Upload handling, a process to keep alive, and a second interface to test. Useful later if another app must call this over the network. Out of this plan.
PyAV or MoviePy only Heavier installs and more decoding code in Python. No ffmpeg binary. Slower, and the hard parts are still the same cuts.

The public function is chunk_video. The command video-chunker is a thin wrapper around it. A later HTTP wrapper can call the same function.

Segment rules

  • duration_s and chunk_s must be greater than zero. Otherwise ValueError.
  • A source shorter than one chunk is one segment from 0 to duration_s.
  • A remainder longer than min_tail_s is its own last segment.
  • A remainder of min_tail_s or less extends the previous segment to duration_s.
  • chunk_video calls the planner with min_tail_s = 1 / frame_rate, so a tail shorter than one frame stays on the previous chunk.

Output rules

  • Filename: f"{source.stem}_{index:04d}.mp4".
  • A stem containing a comma is rejected before ffprobe runs. chunk_video calls chunk_filename(source, 0) and that raises CutError.
  • If the output path exists and is a file, CutError.
  • If any {stem}_dddd.mp4 already exists and overwrite is false, CutError, and those files stay untouched.
  • If overwrite is true, delete every {stem}_dddd.mp4 and {stem}.chunks.json in that folder, then cut.
  • The manifest is written only after every chunk matches the plan. Write it to a temp file, then rename it into place.

      "path": "/absolute/path/chunks/holiday_0000.mp4",
      "start_s": 0.0,
      "end_s": 15.0
    }

}

ffmpeg command

Exact mode, with audio:

ffmpeg -hide_banner -loglevel error -y -i SOURCE \
  -map 0:v:0 -map 0:a:0 \
  -f segment -segment_time CHUNK \
  -reset_timestamps 1 \
  -c:v libx264 -preset veryfast -crf 23 -pix_fmt yuv420p \
  -c:a aac -b:a 128k \
  OUTPUT/stem_%04d.mp4

Fast mode swaps the codec arguments for -c copy. A file with no audio omits -map 0:a:0 and the AAC arguments. Fast mode accepts video codecs h264, hevc, and mpeg4, and audio codecs aac, mp3, ac3, or no audio. Any other codec raises CutError before ffmpeg starts.

After a successful encode, probe each output file. In exact mode the file count must equal the segment count, and each measured duration must sit within duration_tolerance_s(frame_rate) of the planned duration. That tolerance is max(2 / frame_rate, 0.04) seconds. In fast mode, require at least one file and a total measured duration within 0.5 seconds of the source. Timeline fields in the manifest are the planned times in exact mode. In fast mode they are the cumulative probed durations, because keyframe cuts own the real boundaries.

Command line

video-chunker INPUT [--duration 15] [--output ./chunks] [--mode exact|fast] [--overwrite] [--ffmpeg PATH] [--ffprobe PATH]

Stdout is one absolute chunk path per line. Messages go to stderr. Exit 0 on success, 2 on rejection, 1 on cut or verify failure.

Review focus

These five cases are the ones most likely to surprise someone using the tool. Each has a test in the task that owns the behavior.

  1. A video shorter than the chunk length becomes one file of the whole video. Pinned by test_shorter_than_chunk_is_one_segment and test_short_video_writes_one_file.
  2. A length that does not divide evenly keeps the remainder as the last file. Pinned by test_remainder_is_its_own_chunk and test_remainder_chunk_is_kept.
  3. Existing chunk names without --overwrite leave those files byte-for-byte as they were. Pinned by test_prepare_refuses_existing_chunk and test_second_run_without_overwrite_keeps_bytes.
  4. A missing ffmpeg or ffprobe exits 2 and creates no chunk files. Pinned by test_cli_missing_binary_creates_nothing.
  5. Fast mode with a codec that cannot be copied into MP4, such as VP9, exits before ffmpeg runs and writes nothing. Pinned by test_fast_mode_rejects_vp9 and test_chunk_video_fast_reject_writes_nothing.

from video_chunker.models import Segment


def plan_segments(
    duration_s: float,
    chunk_s: float,
    *,
    min_tail_s: float = 0.001,
) -> list[Segment]:
    if duration_s <= 0:
        raise ValueError("duration_s must be > 0")
    if chunk_s <= 0:
        raise ValueError("chunk_s must be > 0")
    if min_tail_s < 0:
        raise ValueError("min_tail_s must be >= 0")

    segments: list[Segment] = []
    start = 0.0
    index = 0
    while True:
        remaining = duration_s - start
        if remaining <= min_tail_s:
            if segments:
                previous = segments[-1]
                segments[-1] = Segment(previous.index, previous.start_s, duration_s)
            break
        end = start + chunk_s
        if end >= duration_s - min_tail_s:
            end = duration_s
        segments.append(Segment(index, start, end))
        if end >= duration_s:
            break
        start = end
        index += 1
    if not segments:
        raise ValueError("duration_s is shorter than min_tail_s")
    return segments


def duration_tolerance_s(frame_rate: float) -> float:
    if frame_rate <= 0:
        return 0.08
    return max(2.0 / frame_rate, 0.04)

# src/video_chunker/probe.py
import subprocess
from pathlib import Path

from video_chunker.models import MediaInfo, ProbeError


def _parse_rate(value: str) -> float:
    if "/" in value:
        num, den = value.split("/", 1)
        den_f = float(den)
        if den_f == 0:
            return 0.0
        return float(num) / den_f
    return float(value)


def parse_probe_json(payload: dict, source: Path) -> MediaInfo:
    streams = payload.get("streams") or []
    video = next((s for s in streams if s.get("codec_type") == "video"), None)
    if video is None:
        raise ProbeError(f"{source} has no video stream")
    audio = next((s for s in streams if s.get("codec_type") == "audio"), None)
    fmt = payload.get("format") or {}
    raw_duration = fmt.get("duration") or video.get("duration")
    if raw_duration is None:
        raise ProbeError(f"{source} has no duration")
    duration_s = float(raw_duration)
    if duration_s <= 0:
        raise ProbeError(f"{source} has a non-positive duration")
    frame_rate = _parse_rate(str(video.get("r_frame_rate") or "0/1"))
    if frame_rate <= 0:
        frame_rate = 25.0
    audio_name = audio.get("codec_name") if audio else None
    return MediaInfo(
        path=source,
        duration_s=duration_s,
        video_codec=str(video.get("codec_name") or "unknown"),
        audio_codec=str(audio_name) if audio_name else None,
        format_name=str(fmt.get("format_name") or "unknown"),
        frame_rate=frame_rate,
    )


def probe_media(source: Path, *, ffprobe_bin: str = "ffprobe") -> MediaInfo:
    result = subprocess.run(
        [
            ffprobe_bin,
            "-v",
            "error",
            "-print_format",
            "json",
            "-show_format",
            "-show_streams",
            str(source),
        ],
        capture_output=True,
        text=True,
        check=False,
    )
    if result.returncode != 0:
        detail = result.stderr.strip() or "ffprobe failed"
        raise ProbeError(detail)
    import json
    return parse_probe_json(json.loads(result.stdout), source)

# src/video_chunker/output.py
import json
import re
from pathlib import Path

from video_chunker.models import ChunkRecord, CutError


def chunk_filename(source: Path, index: int) -> str:
    if "," in source.stem:
        raise CutError(f"{source.name} has a comma in its name; rename it before chunking")
    return f"{source.stem}_{index:04d}.mp4"


def chunk_path(output_dir: Path, source: Path, index: int) -> Path:
    return output_dir / chunk_filename(source, index)


def manifest_path(output_dir: Path, source: Path) -> Path:
    if "," in source.stem:
        raise CutError(f"{source.name} has a comma in its name; rename it before chunking")
    return output_dir / f"{source.stem}.chunks.json"


def existing_chunk_paths(output_dir: Path, source: Path) -> list[Path]:
    if not output_dir.is_dir():
        return []
    pattern = re.compile(rf"^{re.escape(source.stem)}_\d{{4}}\.mp4$")
    return sorted(p for p in output_dir.iterdir() if p.is_file() and pattern.match(p.name))


def prepare_output_dir(output_dir: Path, source: Path, *, overwrite: bool) -> None:
    if output_dir.exists() and not output_dir.is_dir():
        raise CutError(f"{output_dir} is not a directory")
    existing = existing_chunk_paths(output_dir, source)
    manifest = output_dir / f"{source.stem}.chunks.json" if output_dir.is_dir() else None
    if existing and not overwrite:
        raise CutError(
            f"{existing[0].name} already exists in {output_dir}; "
            f"pass --overwrite to replace chunks for {source.stem}"
        )
    output_dir.mkdir(parents=True, exist_ok=True)
    if overwrite:
        for path in existing:
            path.unlink()
        if manifest is not None and manifest.exists():
            manifest.unlink()


def write_manifest(
    output_dir: Path,
    source: Path,
    chunk_s: float,
    mode: str,
    chunks: list[ChunkRecord],
) -> Path:
    path = manifest_path(output_dir, source)
    payload = {
        "source": str(source.resolve()),
        "chunk_s": chunk_s,
        "mode": mode,
        "chunks": [
            {
                "index": chunk.index,
                "file": chunk.path.name,
                "path": str(chunk.path.resolve()),
                "start_s": chunk.start_s,
                "end_s": chunk.end_s,
            }
            for chunk in chunks
        ],
    }
    tmp = path.with_name(path.name + ".tmp")
    tmp.write_text(json.dumps(payload, indent=2) + "\n", encoding="utf-8")
    tmp.replace(path)
    return path

# src/video_chunker/cut.py
from pathlib import Path

from video_chunker.models import (
    MODE_EXACT,
    MODE_FAST,
    CutError,
    MediaInfo,
)

FAST_VIDEO = {"h264", "hevc", "mpeg4"}
FAST_AUDIO = {"aac", "mp3", "ac3"}
EXACT_VIDEO_ARGS = [
    "-c:v", "libx264", "-preset", "veryfast", "-crf", "23", "-pix_fmt", "yuv420p",
]
EXACT_AUDIO_ARGS = ["-c:a", "aac", "-b:a", "128k"]


def assert_fast_mode_compatible(info: MediaInfo) -> None:
    if info.video_codec not in FAST_VIDEO:
        raise CutError(
            f"fast mode cannot copy video codec {info.video_codec} into mp4; use --mode exact"
        )
    if info.audio_codec is not None and info.audio_codec not in FAST_AUDIO:
        raise CutError(
            f"fast mode cannot copy audio codec {info.audio_codec} into mp4; use --mode exact"
        )


def build_ffmpeg_command(
    *,
    ffmpeg_bin: str,
    source: Path,
    output_pattern: Path,
    chunk_s: float,
    mode: str,
    has_audio: bool,
) -> list[str]:
    cmd = [
        ffmpeg_bin,
        "-hide_banner",
        "-loglevel",
        "error",
        "-y",
        "-i",
        str(source),
        "-map",
        "0:v:0",
    ]
    if has_audio:
        cmd.extend(["-map", "0:a:0"])
    cmd.extend([
        "-f",
        "segment",
        "-segment_time",
        f"{chunk_s:.6f}",
        "-reset_timestamps",
        "1",
    ])
    if mode == MODE_EXACT:
        cmd.extend(EXACT_VIDEO_ARGS)
        if has_audio:
            cmd.extend(EXACT_AUDIO_ARGS)
    elif mode == MODE_FAST:
        cmd.extend(["-c", "copy"])
    else:
        raise CutError(f"unknown mode {mode}")
    cmd.append(str(output_pattern))
    return cmd

def _assign_times(paths, segments, mode, ffprobe_bin, frame_rate):
    records = []
    cursor = 0.0
    tolerance = duration_tolerance_s(frame_rate)
    for index, path in enumerate(paths):
        measured = probe_media(path, ffprobe_bin=ffprobe_bin).duration_s
        if mode == MODE_FAST:
            start = cursor
            end = cursor + measured
            cursor = end
        else:
            start = segments[index].start_s
            end = segments[index].end_s
            if abs(measured - (end - start)) > tolerance:
                raise CutFailed(
                    f"{path.name} is {measured:.3f}s; planned {(end - start):.3f}s"
                )
        records.append(ChunkRecord(index, path, start, end))
    return records


def chunk_video(
    source: Path,
    output_dir: Path,
    *,
    chunk_s: float = 15.0,
    mode: str = MODE_EXACT,
    overwrite: bool = False,
    ffmpeg_bin: str = "ffmpeg",
    ffprobe_bin: str = "ffprobe",
) -> list[ChunkRecord]:
    if not source.is_file():
        raise CutError(f"{source} is not a file")
    chunk_filename(source, 0)
    info = probe_media(source, ffprobe_bin=ffprobe_bin)
    if chunk_s < (1.0 / info.frame_rate):
        raise CutError(
            f"chunk duration {chunk_s}s is shorter than one frame "
            f"({1.0 / info.frame_rate:.4f}s)"
        )
    if info.duration_s / chunk_s > 10_000:
        raise CutError("chunk duration would create more than 10000 files")
    if mode == MODE_FAST:
        assert_fast_mode_compatible(info)
    elif mode != MODE_EXACT:
        raise CutError(f"unknown mode {mode}")
    segments = plan_segments(
        info.duration_s,
        chunk_s,
        min_tail_s=1.0 / info.frame_rate,
    )
    prepare_output_dir(output_dir, source, overwrite=overwrite)
    pattern = output_dir / f"{source.stem}_%04d.mp4"
    cmd = build_ffmpeg_command(
        ffmpeg_bin=ffmpeg_bin,
        source=source,
        output_pattern=pattern,
        chunk_s=chunk_s,
        mode=mode,
        has_audio=info.audio_codec is not None,
    )
    result = subprocess.run(cmd, capture_output=True, text=True, check=False)
    if result.returncode != 0:
        detail = result.stderr.strip() or "ffmpeg failed"
        raise CutFailed(detail)
    paths = existing_chunk_paths(output_dir, source)
    if mode == MODE_EXACT and len(paths) != len(segments):
        raise CutFailed(f"expected {len(segments)} chunks, found {len(paths)}")
    if not paths:
        raise CutFailed("ffmpeg produced no chunks")
    records = _assign_times(paths, segments, mode, ffprobe_bin, info.frame_rate)
    if mode == MODE_FAST:
        total = sum(record.end_s - record.start_s for record in records)
        if abs(total - info.duration_s) > 0.5:
            raise CutFailed(
                f"fast mode duration {total:.3f}s is far from source {info.duration_s:.3f}s"
            )
    write_manifest(output_dir, source, chunk_s, mode, records)
    return records

# src/video_chunker/cli.py
import argparse
import os
import shutil
import sys
from pathlib import Path

from video_chunker.cut import chunk_video
from video_chunker.models import MODES, CutError, CutFailed, ProbeError


def resolve_bin(explicit: str | None, name: str) -> str:
    if explicit:
        candidate = Path(explicit)
        if candidate.is_file() and os.access(candidate, os.X_OK):
            return str(candidate)
        raise CutError(f"{name} not executable: {explicit}")
    found = shutil.which(name)
    if not found:
        raise CutError(
            f"{name} not found. Install ffmpeg 5 or newer, or pass --{name}."
        )
    return found


def main(argv: list[str] | None = None) -> int:
    parser = argparse.ArgumentParser(
        prog="video-chunker",
        description="Cut a video into timed MP4 chunks.",
    )
    parser.add_argument("input", type=Path)
    parser.add_argument("--duration", type=float, default=15.0)
    parser.add_argument("--output", type=Path, default=Path("chunks"))
    parser.add_argument("--mode", choices=MODES, default="exact")
    parser.add_argument("--overwrite", action="store_true")
    parser.add_argument("--ffmpeg", default=None)
    parser.add_argument("--ffprobe", default=None)
    try:
        args = parser.parse_args(argv)
    except SystemExit as exc:
        return int(exc.code) if exc.code is not None else 2
    if args.duration <= 0:
        print("duration must be > 0 seconds", file=sys.stderr)
        return 2
    try:
        ffmpeg_bin = resolve_bin(args.ffmpeg, "ffmpeg")
        ffprobe_bin = resolve_bin(args.ffprobe, "ffprobe")
        if not args.input.is_file():
            raise CutError(f"{args.input} is not a file")
        chunks = chunk_video(
            args.input,
            args.output,
            chunk_s=args.duration,
            mode=args.mode,
            overwrite=args.overwrite,
            ffmpeg_bin=ffmpeg_bin,
            ffprobe_bin=ffprobe_bin,
        )
    except CutFailed as exc:
        print(str(exc), file=sys.stderr)
        return 1
    except (CutError, ProbeError) as exc:
        print(str(exc), file=sys.stderr)
        return 2
    for chunk in chunks:
        print(chunk.path.resolve())
    return 0

CutFailed is a subclass of CutError, so the CutFailed handler has to come first. Validation stays on exit 2. A failed encode or a chunk that misses the plan stays on exit 1.

# README.md
# video-chunker

Cut one local video into MP4 pieces of a chosen length.

## Install

ffmpeg 5 or newer is required (`brew install ffmpeg` on macOS).

```bash
python -m pip install -e ".[dev]"
```

## Use

```bash
video-chunker holiday.mp4 --duration 15 --output ./chunks
```

That writes `chunks/holiday_0000.mp4`, then `holiday_0001.mp4`, and so on,
plus `chunks/holiday.chunks.json`. The last file holds any remainder.

`--mode fast` copies packets and can cut on a later keyframe.
`--overwrite` replaces previous chunks for the same file name.

Stdout prints one absolute chunk path per line.

| Exit | Meaning |
| --- | --- |
| 0 | Chunks and the manifest are written. |
| 2 | Bad arguments, missing binary, unreadable media, or existing files. |
| 1 | ffmpeg failed, or a chunk length did not match the plan. |

## Test

```bash
pytest -v
```
